# 回声小屋横屏灰度低保真 SVG

当前版本只包含三张已确认的核心页面，画布尺寸统一为 `844 × 390`：

1. `01_Welcome.svg`
2. `02_Explore_Default.svg`
3. `03_Arrange_Mode.svg`

## 当前移动规则

- Demo 不使用虚拟摇杆；
- 玩家点击或轻触合法可行走位置后，当前控制角色自动移动到目标位置；
- 点击不可行走位置时不启动移动；
- 布置态停用场景点击移动，场景输入用于选择和编辑物品。

## 导入 Figma

1. 打开目标 Figma Design 文件；
2. 将三张 SVG 拖入画布，或使用 **File → Place image**；
3. 每张 SVG 保持 `844 × 390`；
4. 按 `01 → 02 → 03` 横向排列，建议间距 `100 px`；
5. 若中文字体发生替换，统一使用 `Noto Sans SC` 或系统可用的中文无衬线字体。

## 页面关系

- `01_Welcome`：点击“开始”后进入角色创建流程；
- `02_Explore_Default`：点击合法地面位置自动移动；
- `03_Arrange_Mode`：由探索态点击“布置”进入，点击“完成”返回探索态。

当前文件不包含登录、任务、线索、剧情、收集或 NPC 系统。
