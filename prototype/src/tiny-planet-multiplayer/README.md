# 小型球形声音世界多人技术页

独立入口：`tiny-planet-multiplayer.html`

本页复用现有球形世界、点击移动和本地空间声音，不替换单机
`tiny-planet-audio.html`。当前联网范围仅包括：

- 四个固定开发身份；
- 短期开发会话；
- 同一开发星球的 WebSocket 连接；
- 权威球面位置快照；
- 本地玩家预测与远端玩家插值；
- `dev-a / dev-b / dev-c` 与三段现有中文占位语音固定绑定；
- 在线玩家的球面位置直接驱动声音距离，自己与离线玩家静音；
- 开发状态和多人快照面板。
- 服务端确认双方共同停留 20 秒后显示一次轻量回应机会提示；
- 候选阶段不显示任务进度条，相遇不会自动增加共鸣。
- 合格后可主动发出回应，对方接受后显示关系共鸣结果；
- 忽略不会扣除关系进度，重复请求不会重复增加共鸣。

## 输入对照

- `?input=click`：只允许点击球面移动；
- `?input=wasd`：只允许 WASD 连续移动；
- `?input=joystick`：显示手机虚拟摇杆，拖动场景可转镜头；
- 三种模式使用相同速度、镜头、服务器同步和声音参数；
- WASD 按相机朝向解释方向，斜向输入会归一化，不会更快；
- 按住鼠标左键或右键水平拖动可平滑改变相机朝向；
- 镜头只响应主动拖动，不启用悬停转向或指针锁；
- 松开按键或窗口失焦会向服务器发送停止命令。
- 摇杆采用中心死区，松手、触控取消或窗口失焦都会立即停止。

## 本地双端测试

先启动 `backend/` 和 `prototype/` 的开发服务，然后分别打开：

- `tiny-planet-multiplayer.html?user=dev-a&debug=1`
- `tiny-planet-multiplayer.html?user=dev-b&debug=1`

点击任一标签页的球面，另一标签页应在多人快照中看到该玩家移动，并在场景中看到远端占位角色更新位置。

`dev-d` 是无声音的观察身份，适合同时聆听另外三名开发玩家。正式身份、正式声音权限、相遇和关系互动尚未接入本页。
