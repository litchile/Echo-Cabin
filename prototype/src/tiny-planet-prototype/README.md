# 小型球形声音世界 Prototype

这是与现有平面空间版隔离的灰盒实验目录，只验证球形世界是否增强循声探索、停留和往返行为。

## 当前包含

- 一个可点击球面移动的本地玩家占位体；
- 三个固定、可区分的朋友声音占位体；
- 沿球面弧长计算的声音距离与平滑衰减；
- 约 26 秒一圈的灰盒移动尺度，避免小球体十几秒绕行造成的空间压缩；
- 安静背面、单声区域和朋友聚集重叠区域；
- `?debug=1` 开发观察信息与声音范围线。

## 明确不包含

- 美术资产、建筑和环境装饰；
- 任务、送信、奖励或角色互动菜单；
- 多人、服务器、账号和存档；
- 对现有 `spatial-prototype/` 平面版本的替换。

## 本地入口

启动 `npm run dev` 后访问：

- 普通体验：`/tiny-planet-audio.html`
- 开发观察：`/tiny-planet-audio.html?debug=1`
