# Spatial Prototype placeholder audio

`friend-a.wav`, `friend-b.wav`, and `friend-c.wav` are locally generated Chinese placeholder voices.
They exist so the isolated mechanism can run without recording, importing, or a backend.

Before a real user test, replace them with three consented 2–4 second friend voice clips,
normalize their perceived loudness, and keep the filenames unchanged. Do not use feedback
about these synthetic placeholder voices as evidence about the final friend-voice experience.
