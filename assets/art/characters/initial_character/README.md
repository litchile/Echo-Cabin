# 初始角色视角素材

本目录保存 Echo Cabin 当前使用的 Demo 初始角色透明 PNG 设定图，素材版本更新于 2026-07-17。

| 文件 | 视角 |
| --- | --- |
| `01_front.png` | 正面 |
| `02_front_three_quarter_facing_right.png` | 前 3/4，画面朝右 |
| `03_profile_facing_left.png` | 正侧面，画面朝左 |
| `04_rear_three_quarter_facing_left.png` | 后 3/4，画面朝左 |
| `05_back.png` | 背面 |

命名中的 `facing_left` / `facing_right` 均以画面方向为准，避免混淆角色自身左右。

这些文件来自 `美术素材/初始角色/demo初始`，保留原始尺寸与透明通道，未进行缩放、补帧或二次生成。更新时沿用稳定文件名，以免影响项目内引用。
