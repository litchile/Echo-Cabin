## 2026-07-27 移动回归修正

首次多人接入中，本地预测位置会被尚未处理最新点击的旧服务器快照覆盖，表现为角色和镜头后退、停顿或按 10 Hz 快照跳动。

修正方式：

- 权威玩家快照增加 `lastProcessedClientSequence`；
- 客户端忽略早于最新本地点击的快照；
- 服务器确认仍在移动时保留本地连续预测；
- 服务器确认到达后再以权威最终位置收口；
- 大幅偏差仍会触发权威纠正；
- 调试面板增加本机实际渲染坐标，便于区分渲染轨迹与服务器快照。

浏览器连续采样显示本机轨迹单向平滑递进，停止后与另一标签页收到的权威坐标一致。

## 2026-07-27 镜头与角色朝向修正

实际连续点击观察发现：角色经过球顶附近时，旧镜头每帧使用世界坐标重新寻找地理北方。该切线在极区会快速翻转，导致角色、星球和镜头像围绕中心旋转，容易产生眩晕。

修正方式：

- 镜头朝向沿上一帧切线连续传递，不再每帧重新寻找地理北方；
- 镜头增加 1.3 世界单位的跟随缓冲区；
- 角色在缓冲区内移动时星球基本保持稳定；
- 超出缓冲区后镜头以 3.2 世界单位/秒平缓跟随；
- 本地和远端角色都只朝最新点击目标转向，不根据球面经纬度反复扭转；
- 镜头和角色朝向参数保留在 Prototype 配置中，后续可以继续按眩晕反馈校准。

修正后浏览器画面中，角色可以直接横向走向点击点，星球地平线仅发生轻量跟随变化，停止后镜头不继续旋转。

## 2026-07-27 桌面输入对照

- 多人页增加 `点击移动 / WASD` 开发模式选择；
- 点击模式只响应地面点击，忽略 WASD；
- WASD 模式只响应连续按键，忽略地面点击；
- 两种模式共用 2.4 世界单位/秒移动速度、稳定镜头、权威服务器和声音参数；
- WASD 使用相机相对方向，斜向输入会归一化；
- 持续按键每 100ms 更新一次前方球面目标；
- 松开全部按键或窗口失焦会发送权威停止命令；
- 浏览器验证确认连续按键产生移动，松键后服务器恢复停留，WASD 模式点击地面不改变坐标。

后续实际体验发现，仅有相机相对 WASD 但没有相机转向时，移动仍局限于四个固定屏幕方向。已补充桌面镜头控制：

- WASD 模式按住鼠标左键或右键水平拖动可改变镜头朝向；
- W 会沿拖动后的新视线方向前进，因此可形成任意球面行进方向；
- 只开放水平转向，不加入自由俯仰；
- 不使用鼠标悬停转向或强制指针锁；
- 镜头拖动沿当地球面法线旋转，继续遵守稳定镜头和低眩晕规则；
- 单击地面仍不会触发移动。

该对照用于判断连续控制是否比点击移动更容易完成靠近、并行、停留和进入声音重叠区。

手机浮动轮盘已作为第三种隔离输入接入：

- `?input=joystick` 显示左下固定虚拟摇杆；
- 摇杆方向复用相机相对连续移动，网络层仍只接收原有球面目标与停止命令；
- 场景空白区域可单指水平拖动镜头，摇杆区域不会误触镜头；
- 中心死区过滤轻微误触，松手、触控取消和窗口失焦均归零；
- 当前不引入正式移动端 UI，仅用于比较触控连续移动与点击移动的体验。

### 相遇判定最小闭环

- 相遇范围使用 2.2 世界单位，与当前清晰聆听距离一致；
- 两名近期有活动的在线玩家连续靠近 20 秒后，由权威房间把相遇从 `candidate` 更新为 `qualified`；
- 离开范围不超过 3 秒时保留本次累计，超过后结束；
- 最近 60 秒内双方都没有活动时暂停累计，避免挂机产生相遇；
- 候选阶段不向测试者显示倒计时或任务条；
- 合格时只显示一次轻量“回应机会已经出现”，不会自动发放货币或增加共鸣；
- 合格后任一方可以通过带幂等键的 HTTP 写接口发出一次回应；
- 只有另一方可以接受，发起方不能代替对方确认；
- 接受与关系共鸣增加在服务端同一状态转换内完成；
- 同一回应重复接受不会重复增加共鸣，同一玩家对 24 小时内最多增加 1；
- 回应与关系状态进入 Durable Object 本地持久化，并只在相关双方的个性化快照中出现；
- 忽略回应不会扣除资源，待回应在相遇结束后失效；
- `npm run encounter-smoke` 已验证真实双 WebSocket 相遇、HTTP 发起、HTTP 接受和共鸣 `+1` 全链路。
