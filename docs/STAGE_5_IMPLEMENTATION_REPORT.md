# Echo Cabin Web Prototype 阶段 5 实现报告

**日期：** 2026-07-20  
**范围：** 当前角色自声、其他角色距离声音与基础角色混音总线  
**本地状态：** 代码、自动化测试、生产构建和无音频浏览器冒烟通过；真实多角色听感及移动端实机验收待完成

## 已实现

- 复用阶段 4 的统一 `AudioContext`，仅在玩家明确点击“开始体验”或“重播角色声音”后初始化或恢复；
- 页面加载时不自动播放角色声音；
- 每个正式角色拥有长期保留的独立 `GainNode`、声音引用和播放状态；
- 每次开启或重新开始角色声音均创建新的 `AudioBufferSourceNode`，不重复使用已经播放过的一次性 source；
- 每段角色声音自然结束后固定静默 `3 秒`，再使用新的 source 从头播放；各角色周期彼此独立；
- 当前控制角色使用固定自声目标增益 `0.20`，不参与距离衰减；
- 其他角色根据玩家脚底世界坐标之间的距离计算目标增益；
- 距离 `≤ 80` 时目标增益为 `0.45`，距离 `≥ 420` 时为 `0`，中间使用冻结的 smoothstep 曲线连续衰减；
- 角色、玩家移动和当前角色切换后都会重新计算目标增益；
- 增益变化使用 `320 ms` 线性平滑，处于冻结的 `250–400 ms` 范围内；
- 所有角色通道进入 Character Bus，再进入 Master；
- 三个及以下角色时 Character Bus 使用配置值 `0.45`；四角色最密集情况下自动降低到约 `0.323`，使理论输出不超过 `0.5`；
- 角色试听开始前会停止场景角色声音，避免两套声音重叠；
- 场景新增轻量“开始体验 / 重播角色声音”控制，不改动已冻结的角色创建 UI 结构；
- 无正式角色时声音入口禁用，避免创建空 AudioContext 或触发无意义播放。
- 远处目标增益为零的角色也会保持声音循环，靠近后可以直接平滑淡入；
- 角色位置允许重合，不把其他角色作为移动障碍；重合时按照脚底 Y 坐标和稳定角色顺序进行前后景深排序；
- 五个朝向统一使用固定显示高度 `352` 世界单位和底部脚底锚点，不再因原图宽度不同而改变整体身高。

## 验证结果

- `npm run test`：9 个测试文件、59 项测试全部通过（包含后续间歇调度回归测试）；
- `npm run build`：TypeScript 检查与 Vite 生产构建通过；
- 新增自动化覆盖：距离边界、smoothstep 中点、三角色与四角色总线余量、自声增益、距离角色增益、通道复用和每次播放新建 source；
- 浏览器冒烟：创建 UI 正常，场景声音入口可见，无浏览器 `warn` 或 `error`；
- 未在自动化验收中请求麦克风权限、导入用户文件或采集真实声音。

## 尚待人工听感与实机验收

- 创建至少 3 个角色并为其保存真实声音；
- 点击“开始体验”，确认当前角色自声可听且不会以其他角色最大增益播放；
- 移动靠近和远离其他角色，确认声音随距离连续变化，并在 420 世界单位及以外归零；
- 切换当前控制角色，确认自声身份、聆听位置和其他角色距离声音立即重新计算；
- 用 4 个角色验证最密集混音无削波、破音或明显过载；
- 桌面 Chrome、Android Chrome 和 iPhone Safari 的公开 HTTPS 实机检查；
- 阶段 4 尚未完成的 GitHub Pages HTTPS、真实录音/导入与移动端实机冒烟仍需一并补测。
