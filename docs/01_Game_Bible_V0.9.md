# Echo Cabin Game Bible

**中文暂定名：**《回声小屋》  
**英文项目名：** Echo Cabin  
**文档版本：** V0.9  
**上游文档：** Project Charter V0.8  
**文档状态：** Checkpoint 1—4 已确认，Game Bible V1 完成

## 0. 文档职责

本文件只定义玩家进入游戏后实际发生的体验与稳定玩法规则。项目定位、目标用户、验证假设、Demo 范围和成功标准由 Project Charter 维护。具体参数、状态机、界面结构和数据规则进入对应 Spec。

# Checkpoint 1：角色创建与核心循环

**状态：已确认**

## 1.1 角色创建

当前 Demo 最多支持 4 个角色。每个角色分别代表一个具体人物，并设置名字、预设形象和一段当前生效的声音。

同一操作者可以代为创建多个角色，可以现场录制，也可以导入已有音频。代为创建只用于当前 Demo 的声音空间验证，不表示同一个人在正式社交版本中拥有多个正式身份。

## 1.2 当前控制角色

进入探索前，操作者可以从已有角色中选择任意一个作为当前控制角色。

当前控制角色同时承担：

- 移动主体；
- 镜头跟随目标；
- 当前设备的聆听位置；
- 本地自声来源。

其他角色保留在场景中，作为距离声音来源。

## 1.3 玩家移动

- 玩家点击或轻触场景中的合法可行走位置后，当前控制角色自动向目标位置移动；
- 点击新的合法位置时，当前移动目标更新为新位置；
- 点击墙体、边界、物品占用区或其他不可行走位置时，不启动移动；
- 角色到达目标位置或路径被阻断时停止；
- 镜头跟随当前控制角色；
- 声音距离根据角色世界坐标计算；
- Demo 不使用虚拟摇杆。

## 1.4 首次进入

玩家首次进入时先创建第一个角色和声音，再进入场景。进入场景后，可以继续创建更多角色，直到达到 4 个角色的上限。

## 1.5 核心循环

> 创建角色与声音  
> → 选择当前控制角色  
> → 操控角色探索  
> → 听见当前角色声音  
> → 通过距离听见其他角色  
> → 体验多角色声音混合  
> → 创建并摆放回忆物品  
> → 点击物品听见完整声音  
> → 更换声音、位置或当前角色  
> → 再次探索

# Checkpoint 2：角色与声音空间规则

**状态：已确认**

## 2.1 Demo 角色控制

同一时间只存在一个当前控制角色。非当前角色保留上一次移动后的位置，不自主移动，不响应场景点击移动，并继续作为声音来源。

操作者切换当前控制角色后：

1. 原当前角色停止接收输入并保留位置；
2. 新角色成为当前控制角色；
3. 镜头与聆听位置切换到新角色；
4. 原当前角色转为普通距离声源；
5. 新当前角色开始使用本地自声规则；
6. 系统重新计算全部角色声音。

## 2.2 长期多人版本边界

未来接入服务器后，每位参与者创建并控制自己的角色，多个角色同时移动，每台设备以本机角色作为聆听位置，不再允许任意控制其他人的角色。

## 2.3 当前角色自声

正常探索状态中，当前控制角色的声音使用固定且受控的本地音量基准：

- 默认开启；
- 不根据与自身的距离变化；
- 不根据附近角色数量和聚集密度变化；
- 不按照零距离计算为永久最大音量；
- 保持清晰、稳定和可感知；
- 采用间歇重复播放。

回忆物品播放时，自声与其他角色声音一起平滑退到背景，播放结束后平滑恢复。录音试听、编辑和角色切换时，可以暂时改变或暂停自声。

## 2.4 其他角色声音

其他角色声音：

- 只根据与当前控制角色之间的世界距离变化；
- 从角色中心向外连续衰减；
- 在最大聆听距离处自然降为零；
- 不根据屏幕位置、可见性或左右方向改变；
- 不额外增强最近角色；
- 不根据角色数量调整单个角色音量；
- 不限制同时可听角色数量。

Demo 只使用音量表现距离。

## 2.5 播放周期

所有角色声音均采用：

> 播放一段声音  
> → 随机静默 1—3 秒  
> → 再次播放

不同角色的开始时间和静默周期彼此独立。超出聆听范围后可以停止当前周期，重新进入后开启新周期。回忆物品播放期间，角色播放周期可以继续，仅降低最终输出增益。

## 2.6 多角色声音混合

多角色声音由当前角色位置、其他角色位置、固定自声、距离音量和独立播放周期共同形成。当实际混合响度过高时，可以对其他角色声音整体进行柔和控制，但不改变当前自声基准，也不破坏原有距离关系。

# Checkpoint 3：回忆物品与基础互动规则

**状态：已确认**

## 3.1 基础职责

回忆物品默认安静，不因经过、靠近或重叠自动播放。玩家必须进入交互范围并主动点击物品。物品不阻挡玩家移动。

## 3.2 交互提示

- 未绑定物品靠近后显示“点击添加声音”；
- 已绑定物品靠近后显示轻量可聆听反馈；
- 提示不作为独立点击目标，也不长期常驻。

## 3.3 点击与长按

- 点击在松开输入后确认；
- 长按在达到阈值时确认；
- 短按已绑定物品时从头播放；
- 短按未绑定物品时进入声音添加；
- 长按成立后不再触发短按；
- 若物品正在播放，先平滑停止，再进入编辑。

## 3.4 物品播放

- 同一时间只播放一个物品声音；
- 从头播放并保持稳定音量；
- 角色声音退到背景层；
- 玩家可以继续移动；
- 播放开始后，即使玩家离开交互范围，也自然播放至结束；
- 离开范围只取消可交互提示，不中断已经开始的声音；
- 播放期间不能重复触发同一段物品声音，也不能由另一物品抢占播放焦点；
- 播放结束后，玩家需要再次进入交互范围并主动点击，才能从头播放；
- 不保留播放进度。

物品播放期间点击角色不触发额外交互。

## 3.5 物品编辑

编辑状态只包含：

- 添加或替换声音；
- 移动物品；
- 删除物品；
- 完成编辑。

物品的声音操作根据当前绑定状态使用差异化文案：

- 未绑定声音的物品显示“添加声音”；
- 已绑定声音的物品显示“替换声音”。

所有现场操作者都可以编辑任意物品。退出编辑时，点击完成或场景空白；存在未保存修改时先确认。

直接点击未绑定物品添加声音，保存后返回场景。从编辑状态进入声音添加或替换，保存后返回当前编辑状态。

## 3.6 删除

删除前必须二次确认。确认后删除物品、声音、位置和本地数据，不提供自动撤销。

## 3.7 独立摆放模式

选择移动后进入独立摆放模式：

- 当前物品可拖动；
- 玩家角色停止响应场景点击移动；
- 不能播放其他物品、点击角色或编辑其他物品；
- 确认后保存位置并返回编辑；
- 取消后恢复原位置。

## 3.8 合法格点

- 物品只能吸附到预设合法格点；
- 已占用格点不可重复使用；
- 墙体、边界和不可通行区域不能摆放；
- 无效位置不能确认；
- 摆放反馈需区分合法、占用、不可摆放、当前选中和无效状态。

## 3.9 新物品首次摆放

玩家在布置模式中选择新物品后，立即进入首次摆放状态。

- 新物品只能摆放在合法格点；
- 合法位置确认后，物品正式进入场景并占用对应格点；
- 物品正式创建后，系统默认在当前场景上展开声音添加面板；
- 玩家可以立即录制或导入声音，也可以关闭面板并暂时跳过；
- 跳过声音添加不会删除物品；
- 未绑定声音的物品可以在后续布置或探索过程中添加声音；
- 首次摆放取消时，新物品不进入场景、不保留临时位置，也不占用格点。

首次摆放成功后提供视觉反馈，但不自动播放物品声音。只有声音保存成功后，玩家才可在探索态主动点击聆听。

# Checkpoint 4：场景结构与 Demo 内容配置

**状态：已确认**

## 4.1 单一室内场景

Demo 使用一个小型室内场景。场景初始为空，角色和物品由操作者逐步加入。

场景需要自然支持：

- 靠近单个角色时较清楚地听见其声音；
- 靠近多个角色时形成声音重叠；
- 远离角色聚集位置时获得相对安静的空间；
- 在合法区域内摆放回忆物品。

## 4.2 角色容量与测试配置

Demo 最多支持 4 个角色。

- 1 个角色：验证创建、自声、移动和物品；
- 2 个角色：验证当前角色与单个其他角色的声音混合；
- 3—4 个角色：验证多角色重叠和更高声音密度。

角色可以由多人分别创建，也可以由同一操作者代为创建。

## 4.3 角色首次进入位置

每个新角色进入场景时，系统分配一个未被占用的合法出生位置。

- 出生位置不能重叠；
- 不能位于墙体、边界或不可通行区域；
- 只负责首次进入；
- 之后角色可以自由移动；
- 非当前角色保留最终位置；
- 4 个角色位置全部占用后，不再允许新增角色。

## 4.4 回忆物品容量

Demo 支持 2—4 件回忆物品，用于验证单件播放、多件切换、合法格点摆放、共同编辑和删除。

## 4.5 示例内容

示例内容为可选辅助，最低配置可包含 1 个示例角色和 1 件已绑定声音的示例物品。示例内容可以跳过或移除，不计入正式容量。
