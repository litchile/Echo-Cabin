# Echo Cabin UX Flow

**中文暂定名：**《回声小屋》  
**英文项目名：** Echo Cabin  
**文档版本：** V0.5  
**上游文档：** Project Charter V0.9、Game Bible V0.10  
**文档状态：** Sound Creation UI Shell V0.2 同步后冻结

## 0. 文档职责

本文件定义玩家从首次打开 Demo 到进入场景，以及在场景中创建角色、添加角色、切换角色、替换角色声音和布置回忆物品时的页面路径、界面状态与返回关系。

稳定玩法规则由 Game Bible 维护；录音、播放、权限和音量细节进入 Audio System Spec；点击、长按、拖动和模式切换细节进入 Interaction Spec；物品格点与摆放合法性进入 Object Placement Spec。

## 1. 首次进入主流程

> 欢迎页  
> → 角色身份  
> → 角色声音  
> → 进入场景  
> → 极短移动引导  
> → 自由探索

### 1.1 欢迎页

玩家首次打开 Demo 时先进入简短欢迎页。页面只负责：

- 说明这是一个把朋友声音放进小屋的互动体验；
- 提示体验需要录制或导入声音；
- 提供唯一主按钮“开始”；
- Web Prototype 只有在这次明确点击或触摸后才初始化声音，不在页面加载时自动播放。

欢迎页不加入账号入口、复杂教程、长篇世界观或多个功能入口。

### 1.2 权限请求

不单独设置脱离声音操作层的权限说明页面。玩家选择“现场录音”后，先在当前卡片内看到用途与建议时长说明；只有再次明确点击“开始录音”时，系统才请求麦克风权限。

玩家拒绝权限后可选择：

- 重新授权；
- 返回声音选择。

现场录音与本地导入是同等权重的两种来源。权限错误页不使用“改用导入”快捷按钮；玩家返回声音选择后可以重新选择任一路径。

### 1.3 角色创建

角色创建采用两个轻量步骤。

第一步“角色身份”：

- 输入角色名字；
- 以全身形象卡选择预设形象；
- 点击“下一步”。

身份页显示 `1 身份 → 2 声音`；进入声音页后才显示 `身份 ✓ → 2 声音`。名字需去除首尾空格、不能为空且满足集中配置的长度限制。同一预设形象可以被多个角色重复选择。当前只有一个形象时仍显示为已选中的完整形象卡，不显示 AI 生成入口。

第二步“角色声音”：

- 以同等权重选择现场录音或本地导入；
- 可以选择试听候选声音，但试听不是保存前置条件；
- 根据候选来源重新录音或重新选择文件；
- 主动点击“保存声音并创建角色”。

角色必须完成声音设置，不允许创建无声角色。

### 1.4 首次场景引导

第一个角色创建完成后进入场景，并显示极短移动引导：

- 提示点击或轻触场景中的可行走位置；
- 角色自动移动到玩家指定的合法目标位置；
- 说明移动与靠近是聆听空间声音的基础方式；
- 玩家完成一次点击移动并到达目标位置后，引导自动消失。

其他功能不连续弹窗讲解，在玩家触发对应入口时再提供轻量提示。

## 2. 探索态

探索态是场景默认状态。玩家可以：

- 点击或轻触合法可行走位置，让当前角色自动移动；
- 点击新的合法位置时更新移动目标；
- 点击不可行走位置时不启动移动；
- 点击角色、物品或界面控件时优先执行对应交互，不同时设置场景移动目标；
- 通过移动改变镜头与聆听位置；
- 靠近其他角色听见距离声音；
- 靠近并点击已绑定声音的物品进行播放；
- 靠近未绑定声音的物品时添加声音；
- 长按具体物品进入快捷编辑；
- 通过右上角当前角色头像浮层添加角色；
- 点击常驻“布置”入口；
- 通过同一头像浮层切换角色或编辑当前角色声音。

头像浮层、添加角色与布置入口的具体位置和视觉层级在 UI Shell 中验证。

### 2.1 回忆物品聆听流程

> 进入交互范围  
> → 显示可交互提示  
> → 主动点击或触摸物品  
> → 从头播放完整语音  
> → 播放结束  
> → 重新满足范围与主动点击条件后可再次播放

- 进入范围不会自动播放；
- 播放期间不能重复触发同一物品，也不能点击另一物品抢占播放；
- 玩家在播放期间可以继续移动；
- 播放开始后离开交互范围，只取消可交互提示，不中断语音；
- 播放结束后，角色声音恢复，物品回到等待主动触发的状态。

### 2.2 Web 声音恢复与横屏提示

- Web Prototype 从后台返回时，如浏览器挂起声音，显示明确的“恢复声音”入口；
- 恢复入口必须由玩家点击或触摸，不尝试绕过浏览器自动播放限制；
- 移动端以横屏为主要体验方向；竖屏时可以显示轻量“请横屏体验”提示，但不阻止玩家返回或处理声音恢复。

## 3. 添加角色

> 探索态  
> → 点击当前角色头像  
> → 打开轻量角色浮层  
> → 点击“添加角色”  
> → 角色身份  
> → 角色声音  
> → 保存并返回场景

当前 Demo 的添加角色入口只负责创建本地测试角色：

- 同一操作者可以代朋友创建角色，以体验多角色声音相遇；
- 不包装成“邀请朋友”，也不执行真实分享、账号加入或在线邀请；
- 正式邀请和一人一角色的多人流程留待服务器版本定义。

添加角色复用“角色身份 → 角色声音”两个步骤。完成后返回原场景，新角色出现在合法出生位置；原有角色位置、物品、声音与当前控制角色保持不变。

角色达到 4 个上限后，“添加角色”禁用并显示“已达到角色上限”。界面不使用锁图标，也不同时显示空槽加号和重复的添加按钮。Demo 不使用完整 NPC 承担主流程引导；可选示例角色仅用于演示或测试。

## 4. Demo 角色切换

> 探索态  
> → 点击当前角色头像  
> → 打开轻量角色浮层  
> → 选择已有角色  
> → 返回探索态

切换后：

- 原角色停止接收移动输入并保留位置；
- 新角色成为当前控制角色；
- 镜头与聆听位置切换到新角色；
- 自声与其他角色距离声音重新计算。
- 新当前角色使用固定本地自声，原当前角色转为普通距离声源。

点击另一个角色头像后立即完成切换并收起浮层。当前角色使用外圈和勾选标识，不只依赖颜色。浮层同时提供“编辑角色声音”和“添加角色”，但不提供笼统的“编辑当前角色”，以免暗示本阶段支持名字、形象或删除编辑。

该入口只服务于无服务器 Demo。正式多人版本实行一人一角色后可以直接移除，不演化为好友或成员系统。Game Bible 只维护控制权限与切换规则，具体按钮和面板留在本文件。

### 4.1 编辑已有角色声音

已有角色声音编辑是独立流程，不显示创建模式的“身份 → 声音”数字步骤：

> 角色头像浮层  
> → “编辑角色声音”  
> → 试听当前正式声音  
> → 重新录音或重新导入  
> → 试听候选声音  
> → “替换声音”  
> → 保存成功后返回当前声音或场景

- 点击“重新录音”后直接进入录音说明，点击“重新导入”后直接打开文件选择器；不重复出现通用来源选择页；
- 录音候选显示“重新录音”，导入候选显示“重新选择文件”，不得同时并列两种重新操作；
- 候选页可以用低强调“更换声音来源”返回等权来源选择；
- 已有候选后重新录音、重新选择文件或更换来源时，旧候选保留到新候选成功生成；
- 候选声音成功生成后即可使用“替换声音”；试听用于主动确认，但不是替换前置条件；
- 只有“替换声音”保存成功后，候选声音才成为正式声音；
- 编辑层打开时固定目标角色并暂时禁用角色切换，关闭编辑层后恢复；
- 保存成功前，原声音继续生效；
- 取消、返回、权限拒绝、导入失败和保存失败均不影响原声音；
- 保存失败时同时保留原声音和候选声音，允许“重新尝试保存”或“返回试听”；
- 替换成功不改变名字、形象、位置、出生点和当前控制状态。
- 声音编辑层内同一时间只播放一个试听；开始录音、切换试听对象或退出编辑时停止当前试听。

## 5. 布置模式

> 探索态  
> → 点击“布置”  
> → 统一布置模式  
> → 新增或编辑物品  
> → 点击“完成”  
> → 返回探索态

进入布置模式后：

- 当前角色停止移动并保持原位置；
- 场景点击移动停用，点击场景只用于选择物品或取消选中；
- 已有物品立即显示可编辑反馈；
- 界面只常驻“新增物品”和“完成”；
- 不常驻铺开移动、删除、换声音等全部工具。

布置模式采用对象优先结构：玩家先选择物品，再显示该物品的操作。

## 6. 已有物品编辑

选中物品后，在物品附近显示浮动操作按钮。同一时间只能选中一个物品；点击场景空白处取消选中。

未绑定声音的物品显示：

- 移动；
- 添加声音；
- 删除。

已绑定声音的物品显示：

- 移动；
- 替换声音；
- 删除。

浮动按钮不得遮挡物品主体，靠近屏幕边缘时自动换位。删除前必须二次确认。探索态下靠近并长按物品，可直接进入同一物品编辑流程。

## 7. 新增物品

> 布置模式  
> → 点击“新增物品”  
> → 底部物品选择面板  
> → 选择预设物品  
> → 首次摆放态  
> → 确认合法位置  
> → 物品正式创建  
> → 默认展开声音添加面板  
> → 添加声音或跳过  
> → 返回布置模式

### 7.1 物品选择面板

物品选择使用覆盖在当前场景上的底部面板，不进入独立页面。面板只展示：

- 物品缩略图；
- 物品名称；
- 容量上限反馈；
- 关闭入口。

Demo 不提供分类、搜索和筛选。

### 7.2 先摆放，后可选添加声音

选择物品后立即进入首次摆放。合法位置确认后，物品正式进入场景并占用格点。声音不是物品创建条件，玩家可以立即添加、关闭面板暂时跳过，或稍后再添加。

首次摆放取消时，新物品不进入场景、不保留临时位置，也不占用格点。

### 7.3 声音添加面板

首次摆放成功后，声音添加面板在当前场景上默认直接展开，提供：

- 录制；
- 导入；
- 试听；
- 保存；
- 重录或重新导入；
- 关闭或跳过。

录制或导入完成后不自动保存。玩家可以试听，也可以直接主动点击“保存”。新声音只有保存成功后才覆盖原声音；关闭未保存的替换流程时，原声音保持不变。

## 8. 独立摆放态

选择新物品或点击已有物品的“移动”后进入独立摆放态：

- 角色停止移动；
- 只有当前物品可以拖动；
- 不能播放其他物品；
- 不能点击其他角色或编辑其他物品；
- 合法位置可以确认；
- 无效位置不能确认。

新物品确认后正式创建；取消后不进入场景且不占用格点。已有物品确认后保存新位置；取消后恢复原位置。

## 9. 布置模式退出

点击“完成”时：

- 没有未保存修改：直接返回探索态；
- 存在未保存修改：弹出“保存并退出／放弃修改并退出／取消”确认窗口。

已经确认保存的位置与声音不重复触发未保存提示。

## 10. 角色创建的返回与中断

- “角色身份”和“角色声音”之间可以自由返回，并保留形象、名字与当前创建会话中的临时声音；
- 只有玩家退出整个创建流程且存在未保存内容时，才弹出放弃确认；
- 首次角色创建退出后返回欢迎页；
- 从场景添加角色时退出后返回原场景，并保持场景状态；
- 正在录音时隐藏通用返回，只提供“停止录音”和“取消录音”；取消录音丢弃本次未完成录音并返回声音来源，不清理身份 draft；
- 用户关闭系统文件选择器不视为失败；
- 导入或保存处理中暂时阻止退出；
- 处理失败后停留在声音步骤并保留可恢复数据；
- 创建模式从声音页返回身份页时保留候选声音，只有退出整个创建流程才判断是否确认清理；
- 编辑已有角色声音时，存在候选声音则在退出前确认是否放弃候选，原声音始终保留；
- Demo 不实现未完成角色草稿的刷新恢复。

## 12. Figma 低保真范围

第一轮绘制并连线：

1. 欢迎页；
2. 角色身份页；
3. 角色声音页；
4. 探索态；
5. 角色头像浮层、添加角色与容量上限；
6. 角色切换与编辑角色声音入口；
7. 布置态；
8. 物品选择底部面板；
9. 物品选中与浮动操作；
10. 独立摆放态；
11. 声音添加与试听面板；
12. 未保存修改确认弹窗；
13. 已有角色当前声音、录音候选、导入候选与替换失败状态。

第一轮只验证页面层级、常驻入口占用、模式差异、浮动按钮遮挡、返回/取消/完成路径和移动端可操作性；暂不进入正式视觉风格、插画、美术资产或高保真动效。
