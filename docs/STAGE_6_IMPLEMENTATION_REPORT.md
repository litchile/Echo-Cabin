# Echo Cabin Web Prototype 阶段 6 实现报告

**日期：** 2026-07-21  
**范围：** 角色声音固定 3 秒间歇调度与角色位置重合规则同步  
**状态：** 代码、自动化测试与生产构建通过；真实素材听感待项目方验收

## 已实现

- 玩家点击“开启角色声音”后，各角色立即从头播放第一段声音；
- 每段声音自然结束后，该角色固定静默 `3000 ms`，随后使用新的 `AudioBufferSourceNode` 从头播放；
- 当前角色自声和其他角色声音使用相同的固定间隔规则；
- 每个角色维护独立 source 与可取消计时器，不使用 `source.loop`；
- 重新开启角色声音、试听角色声音、替换声音、删除通道或销毁页面时会取消旧 source 和待执行计时器；
- 距离为零或超过最大听觉距离不会改变播放周期，只通过角色 Gain 控制是否可听；
- 角色移动只更新距离 Gain，不停止 source，也不重置已经开始的 3 秒静默计时；
- 角色头像列表、创建层或声音编辑层打开时暂停全部场景角色声音；关闭后仅在打开前已开启的情况下从新一轮恢复；
- 角色不再互相阻挡，玩家可以将多个角色移动到相同脚底位置；
- 角色重合时按脚底 Y 坐标排序；Y 坐标相同时使用稳定 DOM 顺序显示。

## 规则同步

以下稳定规则已同步到 Project Charter、Game Bible、UX Flow 引用、Prototype Scope、Implementation Plan 和 Visual Direction：

- 原“随机静默 1–3 秒”改为“固定静默 3 秒”；
- 角色位置允许重合，不把其他角色视为移动障碍；
- 重合只影响视觉层级，不改变角色 ID、声音来源或距离计算。

## 验证

- `npm run test`：9 个测试文件、59 项测试全部通过；
- `npm run build`：TypeScript 检查与 Vite 生产构建通过；
- 自动化测试验证声音自然结束后 `2999 ms` 内不重播，到 `3000 ms` 时创建新 source；
- 自动化测试验证角色通道复用、source 不复用、自声与距离增益继续生效；
- 自动化测试验证移动更新不会提前结束静默、重启 source 或重置 3 秒计时；
- 真实音频验收需确认每段声音结尾到下一次开头之间约为 3 秒，并确认多个角色各自独立运行。
