# Echo Cabin UX Flow

**中文暂定名：**《回声小屋》  
**英文项目名：** Echo Cabin  
**文档版本：** V0.3  
**上游文档：** Project Charter V0.7、Game Bible V0.8  
**文档状态：** 第一轮移动端低保真验证前冻结

## 0. 文档职责

本文件定义玩家从首次打开 Demo 到进入场景，以及在场景中创建角色、邀请朋友、切换角色和布置回忆物品时的页面路径、界面状态与返回关系。

稳定玩法规则由 Game Bible 维护；录音、播放、权限和音量细节进入 Audio System Spec；点击、长按、拖动和模式切换细节进入 Interaction Spec；物品格点与摆放合法性进入 Object Placement Spec。

## 1. 首次进入主流程

> 欢迎页  
> → 角色身份  
> → 角色声音  
> → 进入场景  
> → 极短移动引导  
> → 自由探索

### 1.1 欢迎页

玩家首次打开 Demo 时先进入简短欢迎页。页面只负责：

- 说明这是一个把朋友声音放进小屋的互动体验；
- 提示体验需要录制或导入声音；
- 提供唯一主按钮“开始”。

欢迎页不加入账号入口、复杂教程、长篇世界观或多个功能入口。

### 1.2 权限请求

不单独设置权限说明页。只有玩家主动选择“录制声音”时，系统才请求麦克风权限。

玩家拒绝权限后可选择：

- 重新授权；
- 改为导入音频；
- 返回声音选择。

### 1.3 角色创建

角色创建采用两个轻量步骤。

第一步“角色身份”：

- 选择预设形象；
- 输入角色名字；
- 点击“下一步”。

第二步“角色声音”：

- 录制或导入声音；
- 试听；
- 重录、重新导入或替换；
- 保存并完成创建。

角色必须完成声音设置，不允许创建无声角色。

### 1.4 首次场景引导

第一个角色创建完成后进入场景，并显示极短移动引导：

- 提示点击或轻触场景中的可行走位置；
- 角色自动移动到玩家指定的合法目标位置；
- 说明移动与靠近是聆听空间声音的基础方式；
- 玩家完成一次点击移动并到达目标位置后，引导自动消失。

其他功能不连续弹窗讲解，在玩家触发对应入口时再提供轻量提示。

## 2. 探索态

探索态是场景默认状态。玩家可以：

- 点击或轻触合法可行走位置，让当前角色自动移动；
- 点击新的合法位置时更新移动目标；
- 点击不可行走位置时不启动移动；
- 通过移动改变镜头与聆听位置；
- 靠近其他角色听见距离声音；
- 靠近并点击已绑定声音的物品进行播放；
- 靠近未绑定声音的物品时添加声音；
- 长按具体物品进入快捷编辑；
- 点击常驻“邀请朋友”入口；
- 点击常驻“布置”入口；
- 点击 Demo 专用“切换角色”入口。

三个主要入口的具体位置与视觉层级在 Figma 低保真中验证。

## 3. 邀请朋友与新增角色

> 探索态  
> → 点击“邀请朋友”  
> → Demo 说明弹窗  
> → “替朋友创建角色”或“稍后再说”

说明弹窗需表达：

- 正式版本中朋友可以创建并控制自己的角色；
- 当前 Demo 暂不支持账号、服务器和在线加入；
- 当前阶段可由操作者替朋友创建角色，以体验多人声音相遇。

选择“替朋友创建角色”后，复用“角色身份 → 角色声音”两个步骤。完成后返回原场景，新角色出现在合法出生位置；原有角色位置、物品、声音与当前控制角色保持不变。

角色达到 4 个上限后，“邀请朋友”显示不可用状态或“角色已满”。Demo 不使用完整 NPC 承担主流程引导；可选示例角色仅用于演示或测试。

## 4. Demo 角色切换

> 探索态  
> → 点击“切换角色”  
> → 打开轻量角色切换面板  
> → 选择已有角色  
> → 返回探索态

切换后：

- 原角色停止接收移动输入并保留位置；
- 新角色成为当前控制角色；
- 镜头与聆听位置切换到新角色；
- 自声与其他角色距离声音重新计算。

该入口只服务于无服务器 Demo。正式多人版本实行一人一角色后可以直接移除，不演化为好友或成员系统。Game Bible 只维护控制权限与切换规则，具体按钮和面板留在本文件。

## 5. 布置模式

> 探索态  
> → 点击“布置”  
> → 统一布置模式  
> → 新增或编辑物品  
> → 点击“完成”  
> → 返回探索态

进入布置模式后：

- 当前角色停止移动并保持原位置；
- 场景点击移动停用，点击场景只用于选择物品或取消选中；
- 已有物品立即显示可编辑反馈；
- 界面只常驻“新增物品”和“完成”；
- 不常驻铺开移动、删除、换声音等全部工具。

布置模式采用对象优先结构：玩家先选择物品，再显示该物品的操作。

## 6. 已有物品编辑

选中物品后，在物品附近显示浮动操作按钮。同一时间只能选中一个物品；点击场景空白处取消选中。

未绑定声音的物品显示：

- 移动；
- 添加声音；
- 删除。

已绑定声音的物品显示：

- 移动；
- 替换声音；
- 删除。

浮动按钮不得遮挡物品主体，靠近屏幕边缘时自动换位。删除前必须二次确认。探索态下靠近并长按物品，可直接进入同一物品编辑流程。

## 7. 新增物品

> 布置模式  
> → 点击“新增物品”  
> → 底部物品选择面板  
> → 选择预设物品  
> → 首次摆放态  
> → 确认合法位置  
> → 物品正式创建  
> → 默认展开声音添加面板  
> → 添加声音或跳过  
> → 返回布置模式

### 7.1 物品选择面板

物品选择使用覆盖在当前场景上的底部面板，不进入独立页面。面板只展示：

- 物品缩略图；
- 物品名称；
- 容量上限反馈；
- 关闭入口。

Demo 不提供分类、搜索和筛选。

### 7.2 先摆放，后可选添加声音

选择物品后立即进入首次摆放。合法位置确认后，物品正式进入场景并占用格点。声音不是物品创建条件，玩家可以立即添加、关闭面板暂时跳过，或稍后再添加。

首次摆放取消时，新物品不进入场景、不保留临时位置，也不占用格点。

### 7.3 声音添加面板

首次摆放成功后，声音添加面板在当前场景上默认直接展开，提供：

- 录制；
- 导入；
- 试听；
- 保存；
- 重录或重新导入；
- 关闭或跳过。

录制或导入完成后不自动保存。玩家先试听，再主动点击“保存”。新声音只有保存成功后才覆盖原声音；关闭未保存的替换流程时，原声音保持不变。

## 8. 独立摆放态

选择新物品或点击已有物品的“移动”后进入独立摆放态：

- 角色停止移动；
- 只有当前物品可以拖动；
- 不能播放其他物品；
- 不能点击其他角色或编辑其他物品；
- 合法位置可以确认；
- 无效位置不能确认。

新物品确认后正式创建；取消后不进入场景且不占用格点。已有物品确认后保存新位置；取消后恢复原位置。

## 9. 布置模式退出

点击“完成”时：

- 没有未保存修改：直接返回探索态；
- 存在未保存修改：弹出“保存并退出／放弃修改并退出／取消”确认窗口。

已经确认保存的位置与声音不重复触发未保存提示。

## 10. 角色创建的返回与中断

- “角色身份”和“角色声音”之间可以自由返回，并保留形象、名字与当前创建会话中的临时声音；
- 只有玩家退出整个创建流程且存在未保存内容时，才弹出放弃确认；
- 首次角色创建退出后返回欢迎页；
- 从场景新增朋友角色时退出后返回原场景，并保持场景状态；
- 正在录音时点击返回，先停止录音并进入试听；
- 导入或保存处理中暂时阻止退出；
- 处理失败后停留在声音步骤，并提供重试或重新选择；
- Demo 不实现未完成角色草稿的刷新恢复。
