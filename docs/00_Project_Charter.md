# Echo Cabin Project Charter

**中文暂定名：**《回声小屋》  
**英文项目名：** Echo Cabin  
**文档版本：** V0.9  
**文档状态：** 已确认，可作为 Game Bible 上游约束

## 1. 项目一句话定义

Echo Cabin 是一个围绕朋友声音构建的互动小世界。玩家可以创建代表自己或朋友的角色，并为每个角色录入或导入一段声音。玩家操控其中一个角色在场景中移动，当前控制角色的声音持续参与空间混合；靠近其他角色时，可以逐渐听见他们的声音。点击回忆物品时，则可以听见被保存在其中的一段声音记忆。

## 2. 核心用户

Demo 优先面向已经拥有共同关系和共同回忆的小型熟人群体，包括室友、同学、情侣、家人和游戏队友。当前 Demo 不优先面向陌生人社交和大型社区。

## 3. Demo 核心假设

1. 不同人物的声音被放入明确角色并进入同一空间后，会比单纯录音播放更有吸引力。
2. 声音绑定到角色或物品，并通过移动靠近和主动点击被听见时，会比普通音频列表更有关系与回忆价值。
3. 空间距离产生的声音重叠，会带来重复探索、展示和分享意愿。

## 4. Demo 范围

### 4.1 角色

- Demo 最多支持 4 个角色；
- 每个角色分别代表一个具体人物；
- 同一操作者可以代为创建多个角色；
- 每个角色分别设置名字、预设形象和一段当前生效的声音；
- 当前 Demo 中，操作者可以选择任意已有角色作为当前控制角色；
- 当前控制角色同时承担移动主体、聆听位置和本地自声来源；
- 其他角色作为距离声音来源存在；
- 非当前角色保留上一次移动后的位置；
- 每个角色只保留一段当前生效声音；
- 角色创建后可以重新录制或重新导入并替换声音；替换保存成功前，原声音继续生效。

长期正式社交版本仍遵循：

- 一个真实参与者对应一个正式角色；
- 每位参与者创建并控制自己的角色；
- 不允许任意控制其他人的角色。

### 4.2 场景

- Demo 使用一个小型室内场景；
- 场景初始为空；
- 新角色进入时，系统分配未被占用的合法出生位置；
- 出生位置只用于首次进入，不限制后续移动；
- Demo 通过点击或轻触合法可行走位置，让当前控制角色自动移动到目标位置；
- 点击墙体、边界、物品占用区或其他不可行走位置时不启动移动；
- 场景需支持单角色较清晰聆听、多角色声音重叠和相对安静的边缘体验；
- 角色位置持续保留。

### 4.3 回忆物品

- Demo 支持 2—4 件回忆物品；
- 每件物品可绑定一段录制或导入的声音；
- 物品默认安静，靠近并主动点击后播放；
- 同一时间只播放一个物品声音；
- 物品播放时角色声音退到背景层；
- 玩家必须在交互范围内主动点击物品，播放开始后即使离开范围也会自然播放至结束；
- 播放期间不能重复触发同一段物品声音，播放结束后需重新满足范围与主动点击条件；
- 物品只能摆放到预设合法格点；
- 已占用、墙体、边界和不可通行区域不能摆放。

### 4.4 声音空间

- 当前控制角色使用固定且受控的本地自声音量；
- 自声不按零距离计算为永久最大音量；
- 其他角色声音根据与当前控制角色之间的世界距离连续衰减；
- 角色声音采用播放后随机静默 1—3 秒的间歇循环；
- Demo 只使用音量表现距离；
- 多角色同时发声时允许自然重叠；
- 物品完整语音优先于角色声音，角色声音优先于环境音。

### 4.5 当前 Demo 的多人验证方式

当前 Demo 不开发账号、服务器和多人实时同步。同一操作者可以创建多个代表不同人物的角色，并在角色之间选择当前控制对象。现场存在多名参与者时，也可以轮流创建和控制各自角色。

场景内提供轻量“添加角色”入口，允许操作者暂时代朋友创建角色，用于验证多角色声音在同一空间中相遇的体验。当前 Demo 不把该入口包装成真实邀请，也不执行分享或在线加入；正式邀请、好友和成员系统留待服务器版本定义。

未来接入服务器后，每位参与者在自己的设备上控制自己的角色，多个角色可以同时移动，服务器同步位置和状态，不再需要单设备角色切换。

## 5. 当前不做

- AI 角色生成；
- 大型自由世界；
- 完整自由建造；
- 正式多人实时联机；
- 正式账号与服务器；
- 复杂经营、任务和 NPC 系统；
- AI 语音克隆；
- 正式商业化。

## 6. 成功标准

- 测试者能够创建至少两个角色并绑定声音；
- 能够选择并控制任意已有角色；
- 能理解当前控制角色自声与其他角色距离声音的区别；
- 会主动点击不同位置，靠近多个角色体验声音重叠；
- 能完成一次物品声音添加、摆放和主动播放，并理解离开范围不会中断已经开始的完整语音；
- 愿意替换声音、调整位置或切换角色再次探索；
- 会想到具体朋友，并愿意把结果展示给对方。

## Project Charter Checkpoint

Project Charter V0.9 已确认：

- Demo 最多支持 4 个角色；
- 同一操作者可以代为创建多个代表不同人物的角色；
- 操作者可以选择任意已有角色作为当前控制角色；
- 已有角色可以重新录制或重新导入声音，且替换成功前保留原声音；
- 角色切换后，镜头、聆听位置、自声和距离声音重新计算；
- 当前规则只服务于无服务器 Demo；
- 长期正式社交版本仍保持一人一个角色、本人创建和本人控制；
- Demo 使用一个小型室内场景；
- Demo 采用“点击合法可行走位置后自动移动”，不使用虚拟摇杆；
- 回忆物品支持声音绑定、主动点击播放和合法格点摆放；
- 已开始的回忆物品语音会完整播放，离开交互范围不再使其停止。
